# Characters and IP records

This folder records where the original characters in these games came from: who
created them, when, with which tools, and what rights apply. Git keeps a dated
history of every change, so this folder doubles as a timeline.

The owner of this repository (GitHub: `rugbyhubby`, site: games.rugbyhubby.com)
created these characters.

| Character | Status | Folder |
|---|---|---|
| **Grandma Dot** ("Grot" once you graduate) | Designed; drawn art done; teaching mode for Euchre in progress | [`grandma-dot/`](grandma-dot/) |
| **Lou** (Dot's late husband, future Cribbage coach) | Idea stage | [`lou/`](lou/) |

## What's in each character's folder

- `README.md`: the character bible (who they are, how they look, how they talk) and a timeline.
- `usage-rights.md`: the terms that cover any AI-generated art, as checked by the owner.
- `art-prompt.md`: the exact prompt used to make the art, so it can be repeated.
- `art/`: the original art files, unchanged. The games use cut-up copies elsewhere
  (for Dot: `p/bmuacrbv/wireframes/dot/art/`).

## Tools used

- **Concept, name, personality and most of the lines:** the owner.
- **Code, wireframes and the first line-drawn sketches:** written with Claude Code
  (Anthropic), working for the owner.
- **The drawn Dot:** generated by the owner with OpenAI's image tool, from the prompt in
  `grandma-dot/art-prompt.md`.

## Notes

- This is a record, not legal advice. If Grandma Dot becomes a product line (greeting
  cards, merchandise), ask an IP attorney about registering a trademark for the name and
  look. Protection mostly comes from the name, the character and how consistently they're used.
- AI-generated images may not be fully protected by copyright, and similar images could be
  made for someone else (see `grandma-dot/usage-rights.md`). The written character
  (name, personality, story, lines) is the owner's own work.
- Keep your own copies of the original files outside this repository too.
- This repository is public, so everything here can be read by anyone.
